# Product

## Vision
Build a private local AI assistant for software development, technical analysis, automation, and local tool orchestration.

## Primary User
A software developer working with projects, source code, documentation, logs, databases, Git, tests, and development tools.

## Core Capabilities
Conversational interaction, project/code exploration, documentation search, file and log analysis, Git inspection, test execution, structured-data analysis, local knowledge retrieval, controlled tool execution, and multi-step workflows.

## Non-Goals for Initial Releases
No unrestricted autonomy, uncontrolled shell access, autonomous production deployment, credential management, unrestricted internet access, or unsupervised destructive code/file changes.

## Principles
Local first. Human controlled. Secure by default. Prefer deterministic tools when deterministic logic can solve the task. Explain consequential actions before execution.
